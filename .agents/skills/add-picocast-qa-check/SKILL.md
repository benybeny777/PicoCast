# QA検査を追加する

1. `DESIGN_implementation_plan.md`のWP-R2-12と`DESIGN_picocast_v3.md` §7を読み、検査ID・対象revision・pass/warn/fail・判定値の責務を既存カタログに合わせる。
2. 閾値は型付き設定から注入し、同じ入力に同じ結果を返す。検査不能を合格として返さず、安定したエラーとデバッグログを残す。
3. 合格例と不合格例を各1件以上用意し、境界値・キャンセルと、自動運用が不合格で投稿を保留する経路を検証する。
4. WP-R2-12の完了時に、実在する検査カタログ・テスト・通知のパスを追記する。R0段階ではQA本体の実装済みと扱わない。
