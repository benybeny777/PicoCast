# ゴールデン基準を更新する

1. `DESIGN_implementation_plan.md`のWP-R2-14と`DESIGN_rust_rewrite.md` §9.3を読み、基準更新の理由と期待する変更を先に記録する。
2. 固定台本・素材・シード・外部ソフトの版を記録し、尺・音量・字幕位置・代表フレームの差分を旧基準と比較する。想定外の劣化は実装修正へ戻す。
3. 理由の記録を必須とする`cargo xtask golden --update`が実装された後にその入口を使う。R0段階では未実装なので、基準ファイルを手作業で作って成功扱いにしない。
4. 新基準で通常検査が成功し、意図的な小さいずれで失敗することを確認する。WP-R2-14完了時に実際の保存先と検証手順を追記する。
