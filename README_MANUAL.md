# YMM4 Auto Video Factory 操作メモ

## 事前準備

- VOICEVOX を起動しておく
- 動画出力まで行う場合は YMM4 を使える状態にしておく
- `.env` に `GOOGLE_API_KEY` を入れておく
- YouTube アップロードを使う場合は `client_secrets.json` と OAuth 認証が必要

## 生成

1. `python gui.py` で起動
2. 必要に応じて `AIタイトル案` でタイトル案作成プロンプトをコピー
3. `AI台本作成` で食べ物雑学特化の台本作成プロンプトをコピー
4. 作成した台本を台本欄に貼り付け
5. 必要に応じて画風を選ぶ
6. `🎬 生成` を押す

生成中に止めたい場合は `作業中止` を押します。押した時点でGUIは中止扱いになり、後続処理へ進みません。Google画像生成やVOICEVOX通信など、外部API呼び出し自体は戻るまで裏で待つことがありますが、戻ってきた結果は成功扱いにしません。

## 複数台本の一括生成

次のどちらかで複数動画として扱われます。

- `---` で区切る
- `━━ 動画1：ショート版 ━━` のような見出しを付ける
- `動画形式:` が複数回出てくる

例:

```text
━━ 動画1：ショート版 ━━
動画形式: Shorts
動画タイトル: A
...

━━ 動画2：ロング版 ━━
動画形式: ロング
動画タイトル: B
...
```

## 履歴から複数生成

`履歴から複数生成` を押すと、`output/` 配下の履歴を複数選択できます。

履歴一覧には最終更新日時が表示されます。`script.txt` がない履歴は再生成対象にできません。

## 画像確認

`画像確認` を押すと、履歴を選んで次の画像を確認できます。

- `thumbnail.png`
- `backgrounds/bg_*.png`

確認画面で再生成したい画像だけ選ぶと、同じファイル名で上書きします。既存の `.ymmp` 参照はそのまま使えます。

## 動画出力

`動画出力` は現在選択中または直近生成した `.ymmp` を YMM4 で開き、MP4 出力を自動操作します。

YMM4 のUIが変わった場合は `core/ymm4_renderer.py` のボタン検出を見直してください。

## YouTube アップロード

`YouTubeアップ` は履歴選択式です。複数の履歴を選択できます。

各履歴フォルダから最新の `.mp4` を探し、`metadata.txt` のタイトル・説明文・タグを使ってアップロードします。アップロード成功後は、その履歴フォルダを `output/000_uploaded/` に移動します。

予約アップロード済みの動画を YouTube Studio 側で手動公開した場合は、次の操作をします。

1. `📅 スケジュール` を開く
2. 手動公開した動画の行を選択
3. `手動公開済みにする` を押す

この操作で、アプリ側の予約スケジュールから該当行を削除し、`output/uploaded_titles.txt` にタイトルを追記します。追記されたタイトルは、`AIタイトル案` の既存タイトル重複回避にも使われます。

`📅 スケジュール` 画面の `選択を削除` は、予約枠だけを消したい場合に使います。手動公開済みとして扱う場合は `手動公開済みにする` を使ってください。

## BGM

固定 BGM として BGMer「のほほん」を自動追加します。

- ファイル: `assets/bgm/nohohon_long_BPM97.mp3`
- 音量: `config.py` の `BGM_VOLUME`
- レイヤー: `config.py` の `BGM_LAYER`

声を邪魔する場合は `BGM_VOLUME` を `10.0` 前後まで下げてください。

## レイヤー

| レイヤー | 用途 |
|---:|---|
| 0 | 背景 |
| 1 | トランジション |
| 2 | BGM |
| 3-4 | 立ち絵 |
| 6 | セリフ字幕 / 音声 |

## 台本作成時の注意

- 背景は展開が変わる時だけ入れる
- 背景プロンプトは日本語で書く
- テロップを入れる場合は `画面上部に"..."を描画` の形にする
- NGワードは自動でマイルド表現へ変換されるが、タイトルや説明文は必要に応じて人間が確認する
- ショートは短く、ロングは理由や比較を増やして展開を作る
