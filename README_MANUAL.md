# 🚀 YMM4 Auto Video Factory 操作説明書

AIと各種生成エンジンを組み合わせ、ゆっくり実況・解説動画のプロジェクトファイル（.ymmp）を全自動で構築する「動画量産システム」です。

---

## 1. 準備（エンジンの起動）

ツールを使用する前に、以下のソフトを起動してください。

1. **VOICEVOX**: 音声合成用（必須）。GUIが自動起動を試みます
2. **YMM4**: 「動画まで自動生成」または「🎬 動画出力」を使う場合のみ必要

---

## 2. 画面レイアウトと基本操作

### 台本エリア（上部）

- **VidIQ などで生成した台本をそのまま貼り付ける**
- 複数本は `---`（ハイフン3つ）で区切って一括処理可能
- 「クリア」ボタンで台本をリセット
- 「📋 VidIQ」ボタン: GUI上部プロンプトをクリップボードにコピー

### オプション行

| 項目 | 説明 |
|---|---|
| 完成後に開く | ymmp ファイルを YMM4 で自動オープン |
| **動画まで自動生成** | 生成完了後に YMM4 で動画出力まで自動実行 |
| デバッグ | 詳細ログを表示 |
| 画風 | nanobanana2（標準）/ nanobanana pro（高品質） |
| 履歴 | 過去に生成したプロジェクトを選択して台本を呼び出し |

### ボタン行

| ボタン | 動作 |
|---|---|
| 🎬 生成 🚀 | パイプライン全体を実行（台本→音声→画像→ymmp保存） |
| 📤 YouTubeアップ | 選択したMP4を直接アップロード |
| 📤 一括アップ | output/ 内のMP4を選択して一括アップロード |
| **🎬 動画出力** | 現在選択中の ymmp を YMM4 で開いて動画出力 |
| 📁 出力フォルダを開く | output/ フォルダをエクスプローラで開く |

## 3. 基本的な使い方

### A. VidIQ連携フロー（推奨）

1. 「📋 VidIQ」ボタンを押してプロンプトをコピー
2. VidIQ / ChatGPT にペースト → 台本を生成させる
3. 生成された台本を**台本欄にペースト**
4. 「🎬 生成 🚀」ボタンを押す
5. 完了後:
   - 「📋 タイトル」「📋 説明文」「📋 タグ」で各項目をコピー
   - 「🎬 動画出力」で動画ファイルを生成
   - 「📤 YouTubeアップ」でアップロード

### B. 動画まで全自動

「動画まで自動生成」チェックボックスをONにしてから「🎬 生成 🚀」を押すと、ymmp保存後に自動でYMM4を起動して動画出力まで実行します。

### C. 複数本一括生成

```
動画タイトル: 1本目のタイトル
動画形式: Shorts
...台本...

---

動画タイトル: 2本目のタイトル
動画形式: ロング
...台本...
```

## 4. 台本フォーマット

### 必須ヘッダー行

```
動画形式: Shorts          ← または「ロング」（解像度・レイアウトが自動切替）
動画タイトル: タイトル
説明文: YouTube概要欄テキスト
タグ: ずんだもん,ゆっくり解説,...
サムネイル: （サムネイル生成プロンプト）
```

### セリフ・背景

```
背景: 夜のコンビニ店内、漫画風、画面上部に"衝撃の事実！"を描画、下半分は空白
ずんだもん(ノーマル): こんにちは！なのだ
四国めたん(ツンツン): ちょっと待ちなさい
```

### 感情タグ

| タグ | 内容 |
|------|------|
| `ノーマル` | 通常 |
| `あまあま` | 明るい・嬉しい |
| `ツンツン` | 怒り・驚き |
| `ささやき` | 小声・シリアス |

### 背景プロンプトのコツ

- 日本語で記述（Nano Banana は日本語テキストを画像内に直接描画）
- キャッチコピーは引用符で囲む: `"衝撃の事実！"`
- 必ず**画面上部のみ・下半分は空白**と明記（立ち絵・字幕エリア確保）
- 特定クリエイター名（新海誠等）は含めない

## 5. 出力ファイル構成

```
output/<動画タイトル>/
├── <タイトル>.ymmp     # YMM4 プロジェクトファイル
├── script.txt          # 補正済み台本
├── thumbnail.png       # サムネイル（Nano Banana生成）
├── metadata.txt        # タイトル・説明文・タグ（コピペ用）
├── audio/              # 音声WAVファイル
└── backgrounds/        # 背景PNG（Nano Banana生成）
```

---

## 6. システム仕様

| 項目 | 内容 |
|---|---|
| 台本生成 | Gemini Flash / Pro |
| 背景・サムネイル生成 | Nano Banana（Gemini画像生成）— 毎回新規生成 |
| 音声合成 | VOICEVOX（毎回新規生成） |
| Shorts解像度 | 1080×1920、立ち絵Y=700（画面下部配置） |
| ロング解像度 | 1920×1080、立ち絵Y=0（中央） |
| レイヤー構成 | 0:背景 / 1:ボイス / 3:立ち絵L / 4:立ち絵R / 5:BGM |
| 背景生成上限 | 1動画あたり最大7枚（config.py の MAX_BACKGROUNDS） |
| 動画出力自動化 | pywinauto で YMM4 GUI を自動操作 |
