# 🚀 YMM4 Auto Video Factory 操作説明書

このツールは、AI（LLM）と各種生成エンジンを組み合わせ、ゆっくり実況・解説動画のプロジェクトファイル（.ymmp）を全自動で構築する「動画量産システム」です。

---

## 1. 準備（エンジンの起動）
ツールを使用する前に、以下のソフトを起動してください。

1.  **VOICEVOX**: 音声合成用（必須）
2.  **Ollama** *(任意)*: ローカル台本生成AI用（フォールバック用）

---

## 2. 画面レイアウトと基本操作
UIは直感的に操作できるよう、上から順に配置されています。

1.  **テーマ入力エリア（上部）**: 動画のネタを入力します。
    - **履歴から選択**: 過去に作った動画の設定を呼び出せます。
    - **クリア**: テーマと台本、両方の入力を一度にリセットします。
2.  **台本エリア（中央）**: 生成された台本の確認・編集、または外部からの貼り付け用です。
3.  **実行ログ・進捗（下部）**: リアルタイムで処理状況を表示します。

---

## 3. 基本的な使い方
### A. タイトルから動画を一括生成
1. 画面上部の **「1. 動画のタイトルを入力」** エリアに、作成したい動画のタイトルを書き込みます。
   - 1行に1つずつ書くことで、複数の動画を連続で生成（一括処理）できます。
   - カンマ区切りでも入力可能です。
2. **「🎬 動画プロジェクト生成」** ボタンを押します。
3. **動作**: AIがタイトルに沿った台本を書き、VOICEVOXで音声を生成し、ComfyUIで背景を描き、最後にYMM4のプロジェクトファイル（.ymmp）を出力します。

### B. 複数台本の一括処理（貼り付け）
すでに完成した台本が複数ある場合、台本エリアに **`---`（ハイフン3つ以上）** で区切って貼り付けてください。
- **動作**: ツールが区切りを検知し、それぞれの台本から個別の動画プロジェクトを生成します。
- **タイトル名**: 台本エリアのみ入力がある場合、各台本の1行目を自動的に動画タイトル（プロジェクト名）に採用します。

---

## 4. AI用おすすめプロンプト（コピペ用）
VidIQやChatGPTなどで、このツールに最適な形式で台本を出力させるためのテンプレートです。

```text
# 指示
以下のタイトルについて、動画編集ソフト「YMM4」用の自動生成台本を【複数まとめて】作成してください。
各台本の間は、必ず「---」のみの行で区切ってください。

# タイトル
1. [タイトル1]
2. [タイトル2]

# 台本の基本構成ルール
1. 各台本の1行目は必ず「動画タイトル」にしてください。
2. 背景指定: 「背景: (シーン描写 + "表示したい文字")」を挿入。
   - 例: `背景: a futuristic office, a glowing holographic sign saying "DANGER", cinematic lighting`
   - **重要**: Nano Banana Proが文字を直接画像内に描き込みます。
3. **テロップタグの廃止**: `テロップ:` タグは現在使用しません。すべての強調文字は「背景」の中に含めてください。
4. セリフ形式: 「名前(感情): セリフ」
   - 名前: ずんだもん、めたん
   - 感情: (ノーマル), (あまあま), (ツンツン), (ささやき), (ヒソヒソ)
5. 区切り: 台本ごとに「---」を挿入。
```

## 5. 安全・便利・高品質機能
- **Nano Banana / Nano Banana Pro**: Googleの最新AIによる次世代画像生成。文字のレンダリングが可能で、背景とテロップが完全に調和します。
- **セーフゾーン設計**: 生成される文字はSNSのUI（いいねボタン等）に被らないよう、中央付近に自動配置されるようAIが調整します。
- **立ち絵自動配置**: 登場キャラクターを判別し、ずんだもんは左、四国めたんは右に自動で配置します。
- **動的キャラ登録**: テンプレートにない新キャラが登場しても、YMM4プロジェクトへ自動的に追加・設定されます。

---

## 6. システム仕様
- **台本生成**: Gemini Flash / Pro (Google AI)
- **背景画像生成**: Nano Banana（Gemini）— 毎回新規生成、キャッシュなし
- **音声合成**: VOICEVOX — 毎回新規生成（uuid ファイル名）
- **解像度**: 通常(1920x1080) / Shorts(1080x1920)
- **レイヤー構成**: 0:背景, 1:ボイス, 3:立ち絵(左), 4:立ち絵(右), 5:BGM
- **Volume スケール**: YMM4 の Volume は 0〜200（200 = UI上100%）
