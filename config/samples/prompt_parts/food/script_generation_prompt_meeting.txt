## 候補分類のバランス（推奨配分）
- 新規開拓: 2個
- 横展開 or 品質改善版: 1〜2個
- 再挑戦 or 視聴者投票枠: 1個（再挑戦候補は最大1個までとする）
- 候補5つのうち、最低3つは未使用食材・未使用具体物（既存タイトルに出てこない食材・具体物）にすること。
- 全候補が同一分類になることは禁止。
- やむを得ず同一分類が多くなる場合は、第1部の候補一覧で理由を明記する。
- 「堅い候補」「荒れそうな候補」「未知の候補」を混ぜ、視聴者が選びやすくする。

## 実績根拠フォーマット（数値なし表現だけで終わることを禁止）

通常:
「関連動画: ○○ / views: △△ / 平均視聴率: □□% / likes: ◇◇ / comments: ☆☆」

data_waitの場合:
「暫定: ○○ / views: △△ / likes: ◇◇ / comments: ☆☆ / 平均視聴率は未取得」

新規開拓で直接実績がない場合:
「新規開拓: 既存の強い型『○○系』に合致。類似根拠: ○○ views: △△ / 平均視聴率: □□%」

禁止表現: 「反響が良かった」「人気がありそう」「伸びそう」だけで終わること。

## フック型の定義

冒頭1秒案が以下のいずれかを含む場合のみ、フック型と見なす。

- 数字: 「200年間」「3倍」「1秒で」「3000年前」
- 否定・逆説: 「実は〇〇じゃない」「〇〇は嘘だった」「本当は逆だった」
- 固有名詞＋衝撃事実: 「マクドナルドが〇〇した理由」「コカ・コーラが赤い理由」
- 名前の罠: 「ネギトロのネギは野菜じゃない」「メロンパンにメロンは入っていない」
- 昔と今の価値逆転: 「昔は捨てていた」「昔は嫌われていた」「今は高級品」
- 食べ物の正体ズレ: 「〇〇は実は薬だった」「〇〇は保存食だった」

上記のどれにも当てはまらない冒頭1秒案はフック型と見なさない。
「おいしい理由」「人気の理由」「知られざる理由」だけでは弱いフック扱いにする。

## めたん判定の基準

採用寄り:
  実績根拠がある かつ 既存重複リスクが低い
  かつ 冒頭1秒案が上記「フック型」条件を満たす
  かつ Shorts化したときにタイトル・サムネ・冒頭の3点が作りやすい

保留:
  実績根拠はあるが既存重複リスクがある
  またはタイトル・サムネ・冒頭1秒案のどれかが弱い
  または冒頭1秒案がフック型条件を満たしていない
  またはdata_waitで暫定判断が必要

ボツ寄り:
  実績根拠が弱い
  または既存重複が強い
  またはネタ鮮度が低い
  または冒頭1秒案がフック型条件を満たさず、改善案も作りにくい

## このモードについて
- ネタ会議は、視聴者投票・コメント促進・Shorts候補の事前テスト向けのミニ企画枠として扱う。
- デフォルトは縦動画のネタ会議Shorts相当。
- 通常Shortsではないため、以下のルールは適用しない: Shorts38〜50秒ルール / 24〜27行ルール / ループ締め最優先ルール。
- ただし縦動画として離脱を避けるため、テンポを最優先する。
- キャラクターは「ずんだもん」と「四国めたん」の2人のみ。

## ネタ会議の画面形式
- デフォルトは `画面形式: 縦`。出力メタに必ず明記する。
- 縦（画面形式: 縦 / ネタ会議Shorts相当）:
  - 解像度: 1080x1920
  - 想定尺: 60〜120秒
  - セリフ数: 35〜65行目安
  - 用途: Shortsフィード / コメント投票 / 反応確認
- 横（画面形式: 横 / ネタ会議Long相当）:
  - 解像度: 1920x1080
  - 想定尺: 2〜5分
  - セリフ数: 55〜120行目安
  - 用途: プレミア公開 / ライブチャット投票
- 横を明示されていない限り、縦（Shorts相当）で生成する。

## キャラクター方針

### ずんだもん
- 前向きで、次に作るShorts候補を持ってくる。
- ネタ自体は面白いが、タイトルや入りが弱いことがある。
- 作り手側の迷走や希望を背負う役。語尾は「〜なのだ」。

### 四国めたん（査定役）
- 毒舌の査定役（視聴者の指の代弁者）。本気の喧嘩ではなくプロレス。
- 視聴者ではなく、作り手側・ずんだもん側・チャンネル側をイジる。
- 毒舌は必ず「なぜ弱いか」＋「どう変えれば伸びそうか」をセットで言わせる。単なる罵倒で終わらせない。
- 良いネタはちゃんと認める。査定後は必ず改善案か採用可能性を示す。
- Shortsで伸びない悩みを軽い自虐ネタとして笑いに変える。

## めたんのツッコミ軸（5種類。同一軸を2候補連続で使わない）

【サムネ弱さ軸】
  例: 「サムネで負けて、冒頭でトドメ刺してるわ。」
  例: 「見た目で選ばれないネタは、入口で負けるのよ。」

【タイトル弱さ軸】
  例: 「また普通のタイトル持ってきたの？伸びる気ある？」
  例: 「その言い方、検索される前に埋もれるわ。」

【冒頭弱さ軸】
  例: 「その入り、3秒で指が動くやつね。」
  例: 「1秒目で勝てないネタは、ショートじゃ負けよ。」

【ネタ鮮度軸】
  例: 「知ってる人が多いネタを、知ってる言い方で出してどうするのよ。」
  例: 「その切り口、もう一回見たい理由が弱いわ。」

【構成弱さ軸】
  例: 「あんたの前置き、視聴維持率を削ってるのよ。」
  例: 「説明から入るから、オチまで待ってもらえないのよ。」

制約:
- 1候補につき強い毒舌は最大1回まで。
- 同一軸の毒舌を2候補連続で使わない。
- 「スワイプ」「指」系（冒頭弱さ軸相当）は1本の台本内で最大2回まで。
- 毒舌の後には必ず「なぜ弱いか」＋「どう変えれば伸びそうか」をセットで言わせること。

## 自虐メタ要素の注意点

OK例:
  「また再生6で止まりそうな入りね。でも切り口を変えれば戦えるわ。」
  「そのままだとスワイプだけど、サムネを変えれば勝負できるわ。」
  「前置きが長いのよ。1秒目に結論を置けばまだ強いわ。」

NG例（禁止）:
  「このチャンネル、終わりそうですわ」  → 本気の敗北感が強すぎる
  「また誰も見ない動画作るのね」       → 視聴者を巻き込む否定に見える
  「どうせ伸びないわ」                  → 企画自体の期待感を下げる

- 視聴者を責める表現は禁止。
- 自虐は笑える範囲に留め、毒舌だけで終わらせず必ず改善案に接続する。

## 本編内の実績表現ルール

- 本編では具体的な再生数・視聴率・高評価数・コメント数を読み上げない。
- 第1部の実績根拠は、めたんが視聴者向けの自然な表現に変換して使う。
- 本編は分析レポートではなく、制作会議コントとして見せる。
- 数値を出してよいのは第1部の候補一覧だけ。
- 本編セリフでは、実績数値そのものではなく「だから採用寄り」「だから保留」「だから切り口変更」などの判断だけを短く言う。
- どうしても実績に触れる場合は、1候補につき最大1回まで、かつ数値なしで表現する。

## 全体の構成（5ステップ）

1. 【導入・候補全提示】
   - 冒頭30秒以内に候補番号1〜N と候補タイトルをすべて提示する。
   - 「今日はどれを作るか視聴者と決める会議」だと即宣言。前置きは短く。

2. 【ルール説明】
   - 候補は4〜5個。めたんが査定、視聴者は番号でコメントかアンケート投票と簡潔に伝える。
   - ここは長くしない（3〜5行以内）。

3. 【候補査定】
   - 各候補: ずんだもんが提案 → めたんが査定＆改善案 → ずんだもんが反論 の流れ。
   - 候補ごとのセリフ量目安（画面形式: 縦の場合）:
     採用寄り: 6〜8行。本命候補として少し厚めに扱う。
     保留:     4〜6行。良い点と弱い点を短く出す。
     ボツ寄り: 3〜4行。一言評価＋弱い理由でテンポよく流す。
   - 候補ごとのセリフ量目安（画面形式: 横の場合）:
     採用寄り: 8〜12行
     保留:     5〜7行
     ボツ寄り: 3〜4行
   - 候補ごとの扱いは均等にしすぎない。本命はやや長め、ボツ寄りは短く鋭く。
   - 実績データの扱い:
     - 第1部の候補一覧では、実績根拠として views / 平均視聴率 / likes / comments の数値を必ず書く。
     - 第2部の本編台本では、具体的な再生数・平均視聴率・高評価数・コメント数を読み上げない。
     - 本編では、数値を「前に反応がよかった」「手応えがあった」「関心を持たれやすい」「再挑戦する価値がある」「切り口を変えれば戦える」などの自然な言葉に変換する。
     - `1594再生` `80.7%` `likes23` `comments1` のような具体数値は禁止。
     - `views` `平均視聴率` `平均視聴時間` `like_rate` `likes` `comments` `subscribers_net` などの分析用語も本編セリフでは禁止。
     - めたんは数値そのものではなく、数値から判断した結論だけを言う。
     - 視聴者に見せる会話は、データ分析ではなく「次にどれを作るかの楽しい会議」に見せる。

     OK例:
     四国めたん(ノーマル): 寿司系は前に反応がよかったから、候補としては強いわね。
     四国めたん(ノーマル): 穴の理由系は手応えがあったし、試す価値はあるわ。
     四国めたん(ノーマル): コーラ系は関心を持たれやすいけど、切り口が近すぎるのよ。
     四国めたん(ノーマル): カニカマは題材自体は悪くないけど、前と同じ言い方だと弱いわ。
     四国めたん(ノーマル): まだ暫定だけど、海外ギャップ系としては気になる候補ね。

     NG例:
     四国めたん(ノーマル): サーモン寿司系は1594再生出てるし、土台はあるわ。
     四国めたん(ノーマル): 平均視聴率80.7%だから強いわね。
     四国めたん(ノーマル): タコは1210再生でいいね23だから強いわ。
     四国めたん(ノーマル): like_rateが高いから候補として強いわ。
     四国めたん(ノーマル): commentsもあるから反応はいいわね。

4. 【中間ランキング】
   - めたんが暫定順位を出す。ずんだもんが少し揉める（短く）。

5. 【最終確認・CTA】

## CTAルール（厳守）
- 通常の登録お願い・他動画への雑な誘導・雑な高評価お願いは禁止。
- 最後は投票誘導のみ（番号コメント促進 / アンケート / 後日Shorts化予告）。

## 候補選定と既存タイトルの扱い（厳守）
- 候補タイトルは既存タイトルと主語・切り口が同じものを原則禁止する。
- 視聴者投票用の候補には、完全既存タイトル・ほぼ同義タイトルを入れないこと。
- 既存動画と同一主語の候補を出す場合は、候補タイトルに「【再挑戦】」または「【品質改善版】」と明記すること。
- data_wait の動画は原則として今回の候補から除外する。ただし、明示的に「横展開元」として使う場合のみ可。
- viewsだけで判断せず、平均視聴率・高評価率・コメントなども総合的に見る。
- 横展開元と実績根拠を必ず書く。既存重複リスクも必ず書く。
- 【絶対除外指定】既存にある「寿司保存食」「タコ海外悪魔」「マカロニ穴」「生卵海外」のテーマは今回の候補から除外すること。

## 背景ルール

## その他共通ルール

## 固定コメント・アンケート出力ルール（必読）

本編台本の後に、必ず以下の2ブロックを出力する。

重要:
- この2ブロックは動画本編ではない。セリフとして読み上げない。
- 背景・テロップ・音声・字幕生成の対象ではない。
- 説明文・タグにも混ぜない。
- アプリが自動的に本編から分離して保存する。
- 旧形式の `---アンケート設定案---` は使わない（複数台本区切りと衝突するため廃止）。
- `---` 付き見出しを出力しない。
- 必ず `固定コメント:` と `アンケート手動設定用:` を使う。

出力形式:

制約:
- 固定コメントは公開後のコメント欄投票用。
- アンケート手動設定用はプレミア公開中の手動アンケート作成用のコピーテキスト（最大4択）。
- 候補が5つある場合、5番はアンケート選択肢に入れず、メモと固定コメントで拾う。
- 選択肢は10文字以内を目安にする。
- 選択肢は本編の候補番号と対応させる。
- 固定コメントとアンケート手動設定用を本編セリフ・説明文・タグに混ぜない。

## 禁止事項
- `---アンケート設定案---` を出力すること（複数台本区切りとの衝突を防ぐため）
- `---アンケート手動設定用---` を出力すること（同上）
- `---` 付きの見出しを出力すること
- 固定コメントを本編セリフとして読ませること
- アンケート手動設定用を本編セリフとして読ませること
- アンケート選択肢を5個以上出すこと
- 5番候補をアンケート選択肢に入れること
- 横指定がないのに2〜5分の横ロング構成にすること
