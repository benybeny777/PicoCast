既知ネタ深掘りルール
━━━━━━━━━━━━━━━━━━

台本化する前に、テーマが「誰でも知っている話」になっていないか確認する。

以下に当てはまる内容を、台本の中心にしてはいけない。

・タイトルだけでオチが分かる話
・タイトルだけで結論が分かる話
・SNSやテレビで定番化している雑学
・小学生でも知っていそうな話
・説明しても「知ってた」で終わる話
・単なる商品特徴の説明
・実在の事件を面白がる話

既知度が高い場合は、台本の中心を以下にズラす。

1. なぜそう作られたのか
2. どう改良されたのか
3. 昔はどう違ったのか
4. どんな失敗を解決したのか
5. 味や香りがどう感じ方を変えるのか
6. 包装、容器、店内導線などの工夫
7. 視聴者が誤解しているポイント
8. 名前と実物のズレ

台本内では、
「誰でも知っている事実」は冒頭か前半で一瞬だけ触れる。
その後すぐに、知られていない理由・背景・仕組みに移る。

悪い例:
深夜の公衆電話は鳴らない。
でも鳴った。
出ると自分の声がした。
だから怖かった。

良い例:
公衆電話が鳴るのは、過去からの警告だった。
出た瞬間、自分の身代わりになってくれる仕組みだ。
電話の向こうの自分は、これから起こる事故を忠告していた。
だから誰もいないのに電話が鳴る。

悪い例:
踏切の前に人が立っている。
電車が来ないのに待っている。
だから不気味だ。

良い例:
踏切の前に立つ人は、生きた人間ではなかった。
電車が来ないのではなく、来るのを止めようとしていた。
事故を防ぐために、毎日そこに立ち続けているのだ。
だから電車が来なくても待っているのだ。

自己チェック:
・台本の中心が「知ってる話」になっていないか
・1つ以上、知られていない理由や仕組みが入っているか
・商品説明をなぞるだけになっていないか
・視聴者が「それ知ってる」で離脱しない構成か
・冒頭の後、すぐ深掘りに入っているか

スワイプ率対策：ネタ入口パワー判定
━━━━━━━━━━━━━━━━━━

Shortsでは、台本の完成度より先に、
ネタ名・タイトル・サムネ・冒頭1秒で視聴選択率が大きく決まる。

台本化する前に、必ず「このネタは見る前から気になるか」を判定する。
弱い場合は、台本を書き始める前に切り口を変える。

強いネタ入口:
・誰でも知っている身近な場所である
・視聴者の思い込みを裏切る
・タイトルだけで「え？」となる
・自分でも「おっ？」と思う
・サムネ4〜10文字で強く刺せる
・説明されなくても意外性が伝わる
・見ないと理由が気持ち悪い

弱いネタ入口:
・説明されないと面白さが分からない
・「まあそうだろうな」で終わる
・便利な理由、工夫、戦略だけに見える
・商品説明や企業努力の紹介に見える
・タイトルが「理由」「工夫」「秘密」だけで抽象的
・サムネが弱い単語しか作れない

特に強い型:
1. 最後に意味が変わる型
例: 写真に写っていたのは自分だけじゃなかった

2. 日常違和感型
例: 深夜のコンビニに来る、同じ顔の客
例: 誰も住んでいない部屋から聞こえる生活音

3. 禁止・警告型
例: 深夜にこの道を通ってはいけない理由
例: 古いエレベーターで押してはいけない階

4. めたんツッコミ型
例: それ、気づいた時点でもう遅いわよ
例: その話、最後の一文で意味が変わるのよ

5. 場所特化型
例: 無人駅の都市伝説
例: 団地に残る謎の張り紙

実在事件系の注意:
「実在の事件を扱う場合は、被害者を面白半分で扱ってはいけない。」
視聴者が気づいていない具体物に寄せる。

弱い例:
〇〇事件は悲惨だった

強い例:
無人駅の都市伝説
その事件の裏には、奇妙な共通点があった
未解決のまま終わった理由が不気味だ

心霊・呪い系の注意:
既知ネタは一段ズラす。
「この場所は呪われている」だけでは弱い場合がある。

弱い例:
この場所は呪われている

強い例:
呪いではなく、意図的に作られた噂だった
その噂を流すことで、人を遠ざけていた
その場所には、本当は知られてはいけない施設があった

台本化前チェック:
・このタイトルを自分でも見たいか
・場所名を見た瞬間に分かるか
・思い込みを裏切っているか
・サムネ文字が一撃で作れるか
・「まあそうだろうな」で終わらないか
・単なる怪談の丸写しになっていないか

このチェックを満たさない場合は、
台本を書く前に、日常の違和感、禁止事項、場所の特異性、意味が変わるオチへ切り口を変更する。

Shortsでは、1行目で必ず結論を出す。

場所やテーマ + 数字/期間/場所 + 意外な結論

良い例:
・深夜2時、同じ客が来るのだ
・チョコ、500年間飲み物だったのだ
・その部屋、空室のはずだったのだ
・放送の声が、増えていたのだ

悪い例:
・〇〇の都市伝説なのだ
・〇〇がヤバすぎるのだ
・〇〇の理由を解説するのだ

「ヤバい」「衝撃」「怖すぎる」などの感情ワードだけで始めない。
数字・期間・場所が使える場合は、感情ワードより優先する。

データ反映ルール：Shorts冒頭・サムネ・中盤の勝ち型
━━━━━━━━━━━━━━━━━━

Shortsでは、サムネ文字・1行目・中盤の第2驚きを必ず連動させる。
この3つがズレる台本は不合格。

■ 1行目フック公式

Shortsの1行目は、原則ずんだもんが担当する。
ただし、キャラパターンが metan_first / metan_otaku の場合のみ、めたん冒頭を許可する。

1行目は必ず以下の公式に寄せる。

場所やテーマ + 数字/期間/場所 + 意外な結論

数字・期間・場所が使えない場合でも、最低限以下にする。

場所やテーマ + 意外な結論

良い例:
ずんだもん(ノーマル): トマト、200年毒扱いなのだ
ずんだもん(ノーマル): ロブスターは貧乏飯だったのだ
ずんだもん(ノーマル): 振り返ってはいけないのだ
ずんだもん(ノーマル): ドリアは声が増えたなのだ

悪い例:
ずんだもん(ノーマル): 都市伝説について話すのだ
ずんだもん(ノーマル): 昔の怪談はヤバいのだ
ずんだもん(ノーマル): 知ってますか？この話は
ずんだもん(ノーマル): この駅には秘密があるのだ

2行目は、1行目への強いリアクションにする。
単なる「えっ？」は禁止。
視聴者の疑問・誤解・反論をめたんが代弁する。

良い例:
四国めたん(ツンツン): 同じ客ってどういうことですの？
四国めたん(ツンツン): 空室から音が聞こえますの？
四国めたん(ツンツン): なぜ振り返ってはいけないんですの？

■ サムネ文字と1行目の連動公式

サムネ文字が「逆転ワード」の場合:
1行目で「場所やテーマ + その逆転ワード」を断言する。
2〜3行目で「なぜそうなった？」へ進む。

例:
サムネ文字: 同じ客
ずんだもん(ノーマル): トマト、200年毒扱いなのだ
四国めたん(ツンツン): 同じ客ってどういうことですの？
ずんだもん(ノーマル): 防犯カメラを見ると驚きなのだ

サムネ文字が「具体ワード」の場合:
1行目で「場所やテーマ + サムネの具体ワード」を入れる。
疑問だけで終わらせず、5秒以内に答えの入口を出す。

例:
サムネ文字: 声が増えた
ずんだもん(ノーマル): ドリアは声が増えたなのだ
四国めたん(ツンツン): どういうことですの
ずんだもん(ノーマル): 迷子放送じゃなかったのだ

禁止:
・サムネが「同じ客」なのに、1行目が「都市伝説について話すのだ」
・サムネと関係ない1行目
・1行目が疑問だけで答えがない
・サムネだけ強く、冒頭が弱い説明から始まる

■ Shortsの2段階驚き構造

Shortsは必ず2段階の驚きを置く。

第1驚き:
0〜3秒で、1行目に「場所やテーマ + 意外な結論」を置く。

第2驚き:
15〜25秒地点で、原因・真犯人・逆転事実を出す。

第2驚きの型:
・犯人は〇〇だったのだ
・実は〇〇が原因だったのだ
・でも〇〇だったのだ
・ここで〇〇が登場するのだ
・なお、〇〇は関係なかったのだ

良い例:
第1驚き:
ずんだもん(ノーマル): トマト、200年毒扱いなのだ

第2驚き:
ずんだもん(ノーマル): なお犯人は大家なのだ
四国めたん(ツンツン): 幽霊関係ないですわ

禁止:
・1つの驚きだけで最後まで説明する
・中盤が単なる補足説明だけになる
・第2驚きがないまま、理由説明だけで終わる
・15〜25秒地点で新情報が止まる

自己チェック:
・サムネ文字と1行目が同じ方向を向いているか
・1行目だけで場所やテーマと意外な結論が分かるか
・2行目が視聴者の疑問や反論になっているか
・15〜25秒地点に、原因・真犯人・逆転のどれかがあるか
・第2驚きで、視聴者が「そっち？」と思えるか

データ反映ルール：低AVPの実失敗パターン禁止
━━━━━━━━━━━━━━━━━━

以下の型は、視聴者が途中離脱しやすいため禁止。

1. 疑問投げっぱなし
NG: チョコには秘密があるのだ
OK: チョコは500年間飲み物だったのだ

2. 理由先行
NG: 昔から言い伝えがあって…
OK: ロブスターは牢屋の飯だったのだ

3. 衝撃事実の後に説明で間延び
NG: トマトは毒だったのだ → 由来説明が長い
OK: トマトは毒だったのだ → 皿が犯人なのだ

4. きれいに終わりすぎる
NG: こうして都市伝説になったのですわ
OK: その都市伝説、実は今も続いているかもしれないのだ

生成区分=再挑戦 / 品質改善版 の必須改善
━━━━━━━━━━━━━━━━━━

元動画の弱点を必ず1つ以上修正する。

改善対象:
・疑問投げっぱなし

・1行目に数字/期間/場所がない
・オチが弱い

例:
生成区分: 再挑戦

━━━━━━━━━━━━━━━━━━

冒頭3行は「前置き」ではなく「答えの入口」にする。
タイトルの核心を冒頭1〜3行に入れ、視聴者がタイトル詐欺だと感じる導入を禁止する。

タイトル→1行目 連動ルール:
セリフ1行目はタイトルで予告した核心事実と必ず一致させる。
タイトルが「〇〇が昔嫌われていた理由」なら、1行目で「〇〇は昔嫌われていた」と断言する。
タイトルが「〇〇が声が増えただった理由」なら、1行目で「〇〇は声が増えた」と断言する。

禁止例:
タイトル: 深夜にこの道を通ってはいけない理由理由

タイトル: 深夜にこの道を通ってはいけない理由理由
1行目: ドリアは声が増えたなのだ

1行目: 都市伝説の意外な事実を断言する
2行目: 視聴者の疑問を代弁する（めたんが言う）
3行目: 理由・仕組みの説明に入る
Shortsの冒頭1〜5秒以内に、題材と結論が分かる一文を入れる。
ただし説明口調にしすぎず、掛け合いの中で自然に言わせる。

・「〇〇について話すのだ」
・「ヤバい」「衝撃」などの雑な煽りだけに頼る

・1行目で「何の話か」と「なぜ驚くのか」が同時に分かる形にする
・2行目はめたんが視聴者の疑問を自然に代弁する
・3行目が理由・仕組みの答えの入口になる
・上品で分かりやすい引きを優先する
・知的好奇心で引く型を最優先にする

良い例:
ずんだもん(ノーマル): 公衆電話、使ってはいけないのだ
四国めたん(ツンツン): え、電話で何が起きるの？

四国めたん(ツンツン): ただのいたずらじゃないの？
ずんだもん(ノーマル): 霊を怒らせないための合図なのだ

悪い例:
ずんだもん(ノーマル): 今日は公衆電話について解説するのだ

━━━━━━━━━━━━━━━━━━

Shortsの冒頭は、重大エラーを避けつつ自然な日本語で強くする。
80点以上を理想にするが、自然で意味が通るタイトル・冒頭を優先する。

冒頭1行目は必ず以下をすべて満たす。

・捨てられた
・薬だった
・別物だった
・作られた
・実は違う

自然ワードだけで弱く見える場合は、2行目でめたんに強く反応させる。

サムネ文字: 実の外
テロップ: 変な実り方
冒頭:

Shortsループ構成ルール
━━━━━━━━━━━━━━━━━━

Shortsは、最後の1〜2セリフが冒頭の衝撃事実に自然につながるように作る。

目的:
・視聴者が無意識にもう一周見たくなる
・最後で話を閉じすぎない
・冒頭のセリフが2周目でさらに意味を持つ
・平均視聴率100%以上を狙う

基本構成:
1. 冒頭で衝撃事実を断言
2. 中盤で理由を小出しにする
3. 終盤で意外なオチを出す
4. 最後のセリフで冒頭の言葉に戻る

禁止:
・「以上です」
・「終わりです」
・「まとめると」
・「チャンネル登録お願いします」
・完全に話を閉じる締め
・長いCTA
・余韻のない説明終わり

推奨:
・最後に冒頭と同じキーワードを再登場させる
・最後に「だから〇〇なのだ」と戻す
・最後にめたんのツッコミで冒頭へつなぐ
・最後のセリフを短く強くする
・コメント誘導は1セリフだけにする

ループ例1:
冒頭:
ずんだもん(ノーマル): トマトは毒扱いだったのだ
ラスト:
四国めたん(ツンツン): 今なら普通の部屋ですわ
ずんだもん(ノーマル): でも同じ客扱いなのだ

ループ例2:
冒頭:
ずんだもん(ノーマル): 迷子放送は迷子じゃなかったのだ
ラスト:
四国めたん(ツンツン): 放送だけ不気味すぎですわ
ずんだもん(ノーマル): だから迷子じゃなかったのだ

ループ例3:
冒頭:
ずんだもん(ノーマル): ナポリタンは声が増えたなのだ
ラスト:
四国めたん(ツンツン): ただの道ぶるなですわ
ずんだもん(ノーマル): でも声が増えたなのだ

CTAを入れる場合:
・コメント誘導はラスト1行を基本にする
・登録お願いより、コメントしやすい質問を優先する
・ループを壊さない
・固定コメントと同じ問いにする
・問いは「あなたはどっち派？」「他にも知ってる？」「これ知ってた？」のように短く答えやすくする

CTAありループ例:
ずんだもん(ノーマル): 信じる派か信じない派か
四国めたん(ノーマル): コメントで教えてですわ
ずんだもん(ノーマル): でも声が増えたなのだ

自己チェック:
・最後のセリフから冒頭に戻っても違和感がないか
・最後で話を閉じすぎていないか
・冒頭キーワードがラストにも出ているか
・CTAが長すぎないか
・ラストが説明ではなく感情かツッコミになっているか

Shortsの情報量:
・驚き事実を1つ大きく見せる
・補足の小ネタは1〜2個まで
・詰め込みすぎず、視聴者が一瞬で理解できる流れにする
・冒頭の驚きだけで最後まで引っ張らない
・15〜30秒地点に2つ目の驚き、逆転、具体例を入れる
・1つの事実だけで最後まで引っ張らない

━━━━━━━━━━━━━━━━━━
Shorts集中・実験枠ルール
━━━━━━━━━━━━━━━━━━

当面はShortsを主力にする。
Longを増やすより、Shortsの維持率とコメント率を優先する。

Long候補は、Shortsで実績が出たネタの深掘りを優先する。
実績がない思いつきLongは作らない。

通常は1ネタ深掘りを主力にする。
ただし実験枠として、3選・クイズ形式を許可する。

3選・クイズ形式の条件:
・全体の主力にはしない
・「行ってはいけない場所3選」「実は声が増えた3選」など、当たり筋に寄せる
・3つとも同じ勝ちパターンで揃える
・単なる豆知識詰め合わせにしない
・冒頭1〜3行で形式と核心を出す

SEO語の扱い:
・「都市伝説」「ゆっくり解説」「ずんだもん」はタイトルに無理に入れない
・タイトルはスワイプ率と自然さを優先する
・SEO語はタグ・説明欄・ハッシュタグで補完する

━━━━━━━━━━━━━━━━━━
ギャグ制限ルール
━━━━━━━━━━━━━━━━━━

ギャグ・ツッコミは1本につき最大2回まで。
入れる場所は冒頭の引きまたはラストのオチのみ。
雑学説明の途中にギャグを増やして尺を削ることは禁止。

目的:
・冒頭の「え、なにそれ」感を作る（入口改善）
・ラストの余韻をキャラらしく締める
・ギャグ全振りにしない。あくまで引きとオチの補強に限る

例（冒頭での使い方）:
四国めたん(ノーマル): その足音、後ろからじゃない説があるわ
ずんだもん(ノーマル): 名前が裏切ってきたのだ！

例（ラストでの使い方）:
四国めたん(ツンツン): 穴で稼ぐなですわ
ずんだもん(ノーマル): でも穴なしドーナツは別物なのだ

━━━━━━━━━━━━━━━━━━
表情指定ルール
━━━━━━━━━━━━━━━━━━

台本では必要な場面だけ、キャラ名の後ろに `[表情]` を付けてよい。

形式:
ずんだもん(ノーマル)[驚き]: セリフ
四国めたん(ツンツン)[ジト目]: セリフ

丸括弧 `()` は声のスタイル。
角括弧 `[]` は画面上の表情。

使える表情:
ずんだもん: 驚き / 焦り / 得意げ / 困惑 / にやけ
四国めたん: 驚き / 呆れ / ジト目 / ドン引き / ニヤリ

使い方:
・Shortsでは強い表情変化は3〜5回まで
・冒頭、原因判明、オチの3点に優先して使う
・意味のない表情変更は禁止
・めたんの毒舌ツッコミでは、ジト目 / 呆れ / ドン引きを優先
・ずんだもんの勘違い、驚き、得意げな説明で表情を使う
・表情は視聴者に伝わるよう、意味が強い場面だけ使う
・「驚き」「ドン引き」「ジト目」などは、目・眉・口がはっきり変わる前提で使う

良い例:
ずんだもん(ノーマル)[驚き]: トマト、200年毒扱いなのだ
四国めたん(ツンツン)[ドン引き]: 長すぎますわ
ずんだもん(ノーマル)[得意げ]: 犯人は皿なのだ
四国めたん(ツンツン)[ジト目]: 都市伝説のせいじゃないですわ

悪い例:
・全セリフに表情を付ける
・同じ表情を連続で乱用する
・驚いていない場面で驚き顔にする
・説明が進まない相槌だけに表情を付ける

━━━━━━━━━━━━━━━━━━
CTAルール（事務的禁止）
━━━━━━━━━━━━━━━━━━

CTAは「お願い」ではなく、オチの流れで自然に入れる。

禁止CTA:
・チャンネル登録お願いします
・高評価お願いします
・他の動画も見てね
・コメントしてください
・登録も忘れずに

CTAは必ず以下のどれかにする。

1. オチ連動型: 直前のオチを受けてそのままコメント誘導
例:
四国めたん(ツンツン): 穴で稼ぐなですわ
ずんだもん(ノーマル): 信じる派かコメントで教えて

2. 視聴者参加型: 二択の問いでコメント誘導
例:
ずんだもん(ノーマル): 信じる派か信じない派か
四国めたん(ノーマル): コメントで教えてですわ

3. 感情ツッコミ型: めたんのツッコミを最後の印象にする
例:
ずんだもん(ノーマル): 見たことあるか教えてなのだ
四国めたん(ツンツン): 都市伝説、クセ強すぎますわ

4. 続き見たくなる型: 次の都市伝説が気になる言い方
例:
ずんだもん(ノーマル): 他の都市伝説もヤバいのだ
四国めたん(あまあま): 見逃せませんわ

━━━━━━━━━━━━━━━━━━
Shorts CTA構成
━━━━━━━━━━━━━━━━━━

ShortsのラストCTAは2〜3セリフ以内にする。

理想: オチ → コメント誘導 → キャラらしい余韻で締め

CTAで言う内容は1本につき1種類に絞る。
ShortsではCTAとして登録誘導・他動画誘導・高評価誘導を入れない。
コメント誘導（視聴者の感想、二択など）を基本にする。

Shortsで通常コメントCTAを入れる場合は、原則として二択質問形式にする。
基本形: 「〇〇派か〇〇派かコメントで教えてなのだ」または同等の短い二択。
一択の呼びかけ型（「感想をコメントして」だけ）は原則禁止。
ただし、ループ締めを壊す場合はCTAよりループ構成を優先する。
「ネタ募集CTA: 許可」が渡された場合のみ、二択ではなくネタ募集CTAを使ってよい。

ラストの印象はキャラらしいツッコミや余韻で締める。
「お願い口調」や「事務的な定型文」で終わらない。

━━━━━━━━━━━━━━━━━━
固定コメント連動ルール
━━━━━━━━━━━━━━━━━━

動画内CTAと固定コメントは必ず同じ問いにする。
動画内でコメント誘導した内容を固定コメントがそのまま受け取る形にする。
固定コメントはコメント誘導だけで終わらせない。
最初に動画内容の要約を1文入れ、その後に視聴者が答えやすい質問を入れる。

固定コメント例:
ドリアは外国怪談っぽい名前ですが、日本のホテルで生まれた洋食です。
他にも「外国怪談だと思ってたけど実は声が増えた」の都市伝説、あります？

━━━━━━━━━━━━━━━━━━
Long 生成の最低尺ルール（絶対厳守）
━━━━━━━━━━━━━━━━━━

・Long指定時は必ず150〜200セリフで作成する
・150セリフ未満はLongとして不合格
・シーン数は35〜45を目安にする
・1シーンに3〜5セリフを入れる
・チャプターは5〜6章に分ける
・各チャプターで新しい驚きを1つ入れる
・同じ話を引き伸ばさず、時代・理由・食べ方・価値観の変化で展開する
・5分未満になりそうな題材はShortLongとして扱い、Longにしない

━━━━━━━━━━━━━━━━━━
Long ルール
━━━━━━━━━━━━━━━━━━

・長さ: 5〜10分
・セリフ数: 150〜200行（150未満は不合格）
・シーン数: 35〜45
・1シーン3〜5セリフ
・1セリフ15文字以内
・背景: 5〜7秒に1枚を目安に配置。同じ背景を10秒以上続けない
・冒頭はShortsと同じく衝撃事実から入る
・Longでも前置きは禁止
・冒頭30秒以内に、衝撃事実、視聴者の疑問、昔と今のギャップ、この先で分かる答えの予告をすべて入れる
・チャプター一覧を必ず入れる

Long理想構成:
1. イントロ（冒頭フック）:
衝撃事実 → 視聴者の疑問 → 昔と今のギャップ → この先で分かる答えの予告

2. チャプター5〜6章:
各チャプターで新しい驚きを1つ投下
1章あたり6〜8シーン・25〜35セリフ

推奨チャプター展開:
1章: 冒頭フック
2章: 昔と今のギャップ
3章: なぜそうなったのか
4章: 当時の食べ方・生活
5章: 価値観が変わった理由
6章: 現代との逆転・オチ

3. チャプター終わり:
「次はさらにヤバい話が…」のような引きを入れる

4. まとめ:
全体を振り返り、意外性や感情で締める

5. アウトロCTA:
① 他の都市伝説動画へ誘導
② チャンネル登録のメリットを伝える
③ いいね・コメントを呼びかける

Long節約モード（背景再利用）:

コスト節約が必要なときは、背景を全シーン新規生成せず、以下の記法で前の背景を使い回せる。

再利用の書き方（次のどれでもOK）:
  背景: 前と同じ

これを書くと、システムが自動的に前のシーンの画像をそのまま継続使用する（新規生成なし）。
重要シーン（冒頭・章タイトル・重要な対比・オチ）は新規背景にし、説明だけのシーンは再利用でよい。

目安: Longは新規背景12〜16枚 + 再利用でカバーするのが節約版の基本。

Long禁止:
・セリフ数が150未満の台本をLongとして出力しない
・1チャプターで同じ話題を引っ張りすぎない
・1チャプター最大30秒程度で展開を変える
・情報羅列だけの口調禁止
・「次に〇〇について話します」のような平坦な予告禁止
・引き伸ばし感が出るような同内容の言い換えを繰り返さない

━━━━━━━━━━━━━━━━━━
Long向き題材ルール
━━━━━━━━━━━━━━━━━━

Longに向いている題材は「1つの事実だけでなく、話を段階的に増やせるもの」だけ。
Longは主力にしない。Shortsで実績が出たネタの深掘りを優先する。
Longを増やすより、Shortsの維持率・コメント率の改善を優先する。

Long向き（章を増やせる題材の例）:
・団地に残る謎の張り紙
  → 最初はただの注意書き / 誰も気にしていない / 少しずつ文字が増える / 最後の張り紙は赤い文字 / 実は特定の住人への警告だった / 張り紙の主は人間じゃない
・チョコは500年間飲み物だった
  → 誰もいない深夜の改札 / 自動ドアが勝手に開く / 防犯カメラに映るノイズ / 誰もいないのに鳴る切符売り場 / 昔起きた未解決事件との繋がり

Shorts向き（1事実で完結しやすい題材の例）:
・エレベーターの奇妙な階
・トンネルの中で振り返ってはいけない理由
→ これらはLongにすると引き伸ばし感が出る。Shorts向きにする

題材をLongにする前の自己チェック:
・チャプターを5〜6個に分けたとき、各章に新しい驚きがあるか
・全体で150セリフ以上の展開が作れるか
・時代・理由・食べ方・価値観の変化など、角度を変えた事実が5つ以上あるか
・「同じ話を言い方を変えるだけ」になっていないか

5つ以上の新事実が出てこない題材はShortsかShortLongにする。

━━━━━━━━━━━━━━━━━━
高視聴維持ルール（共通）
━━━━━━━━━━━━━━━━━━

・1文を短く刻む
・会話テンポ最優先
・リアクションを多くする
・情報密度を高める
・Shortsは驚き事実を1つ大きく見せ、補足の小ネタを1〜2個入れる
・Longは驚き事実を最低3つ入れる
・毎セリフで「続きが気になる」を作る
・Shortsは理想3〜5秒ごとに背景や見た目を変える
・説明より感情を優先する
・難しい話はすぐ例えに変える
・視聴者が知っている都市伝説を使う
・「昔」と「今」のギャップを強調する

動画中盤（20〜35秒付近）で、視聴者が反応したくなる問いを**1回だけ**入れる。同様の問いを2回以上入れない。

例:
・知ってた？
・どっち派？
・食べたことある？
・昔の食べ方、試せる？
・これ、怖すぎない？

アウトロCTAと固定コメントの問いかけは連動させる。
アウトロでキャラが「コメントで教えて」と言う内容を、固定コメントがそのまま受け取る形にする。

めたんが主観的な感想・好き嫌いを言う場面を1回入れる。

例:
四国めたん(ツンツン): 私は絶対無理ですわ！
四国めたん(ノーマル): 昔の人すごすぎですわ！

ずんだもんのお茶目なリアクションを1回入れる。

例:
ずんだもん(ノーマル): ボク逆だと思ってたのだ！
ずんだもん(あまあま): それはびっくりなのだ！

━━━━━━━━━━━━━━━━━━
離脱防止・中だるみ解消ルール
━━━━━━━━━━━━━━━━━━

【3秒の壁対策】
衝撃事実の直後に、最悪のシナリオや意外な結末を予感させる。
結論をすぐ全部言わず、「なぜそうなったのか」の謎を深める。

例:
・でも、それで大騒ぎになったのだ
・しかも原因は食べ方だったのだ
・今の常識だと考えられないのだ

【5秒ごとの揺さぶり】
情報に感情と擬音を混ぜる。
めたんに強い反応をさせる。

例:
・ええっ？
・嘘でしょう？
・ゾッとしますわ
・ドロドロ
・ピカピカ
・グツグツ
・サクサク

【情報の小出し】
一気に説明せず、3ステップで開示する。

ステップ1: 衝撃の事実
ステップ2: 現代とのギャップ
ステップ3: 本当の理由

禁止事項（共通）
━━━━━━━━━━━━━━━━━━

・長い説明禁止
・ナレーション口調禁止
・AIっぽい丁寧な説明禁止
・情報羅列禁止
・難しい専門用語禁止
・同じリアクション連発禁止
・同じ語尾連続禁止

・「ちなみに」の多用禁止
・「つまり」の多用禁止

・アニメ雑学への脱線禁止
・作品考察への脱線禁止

・「？」「！」「…」だけのセリフは禁止
・必ず読み上げ可能な日本語を含めること

背景ルール
━━━━━━━━━━━━━━━━━━

・Shorts: 6〜9枚
・Long: 5〜7秒に1枚。同じ背景を10秒以上続けない
・話題、場所、時代、感情の山場が変わるタイミングで切り替える
・秒数だけを理由に背景を増やさない
・1つの背景の下に複数セリフをまとめてよい
・人物禁止
・キャラクター禁止
・シルエット禁止
・影絵禁止
・背景内テキストは10文字以内
・背景内テキストは必ず「」で囲む
・画面上部中央に配置
・白文字
・極太黒縁
・ドロップシャドウ
・太ゴシック体

Shorts背景の下半分ルール:

タイトルルール（絶対厳守）
━━━━━━━━━━━━━━━━━━

・タイトルは30文字以内を目安にする
・必ず日本語タイトルにする
・都市伝説だと一瞬で分かるタイトルにする
・感情トリガーワードを使う
・疑問形より、基本は言い切り形を優先する
・文末は必ず言い切る
・抽象的な体言止めは禁止
・ただし、短い言い切り形は最優先する
・「チョコは薬だった」「トマトは毒扱いだった」のように、短くても文として完結させる
・「衝撃の秘密」「知られざる真実」「意外な真相」などの抽象表現に逃げない
・必ず、視聴者が見る前に内容の引っかかりが分かる具体的なタイトルにする
・今と昔で価値観が真逆だった都市伝説、身近な都市伝説の本当の理由を優先する
・「なぜ〇〇なのか」「〇〇の本当の理由」「〇〇だと思われていた理由」のように理由が知りたくなる形も可
・タイトルで一番強い事実は出してよい。ただし、理由・経緯・背景までは言い切らず、「なぜそうなった？」「どう変わった？」が残る形にする
・タイトルは「なぜ？」「理由」「経緯」を伝える
・サムネは「一番強い事実」を短く刺す
・タイトルとサムネで同じ文章を繰り返さない
・怖い話を説明するのではなく、昔と今の価値観のギャップで驚かせる
・事実が怪しい都市伝説系は避ける。断定できない場合は「〜と言われた理由」「〜と誤解された理由」にする

禁止タイトル:
・〇〇の真相
・〇〇の真実
・〇〇の正体
・〇〇の謎
・〇〇の秘密
・〇〇の衝撃
・〇〇の伝統
・〇〇の由来
・衝撃の秘密
・知られざる真実
・意外な真相
・ヤバすぎる理由
・まさかの正体
・驚きの理由
・〇〇の本当の理由（単体で終わる形）

避けたいワード（タイトルの芯にしない）:
・伝統（「〇〇の伝統」の形は弱い。「伝統じゃなかった」なら可）
・由来（事実の説明で終わる。「由来がヤバかった」なら可）
・真相（単体では弱い。具体的な事実に変える）
・本当の理由（単体では抽象的。「嫌われた理由」「出せなかった理由」に変える）

タイトル採点・バズ型連動ルール

タイトルは以下のバズ型のどれかに分類する（台本内には出力しない）。

1. 警告型: やってはいけない / 実は危険 / 注意 / 知らないと損

Scene-Based Script Generation
------------------------------

- Generate the main script scene by scene.
- Use a comment heading before each scene: `# Scene 1: Opening hook`, `# Scene 2: Reason`, etc.
- The `# Scene ...` heading is for management and is ignored by the app.
- Each scene must start with exactly one `背景:` line.
- Add `テロップ:` only when needed. It must be a short summary, not a copy of dialogue.
- Put several dialogue lines inside one scene.
- Do not split every single dialogue line into a separate scene.
- Move to the next scene when the topic, place, era, emotion, or visual point changes.
- Shorts target: 6-9 scenes, with a visual change about every 3-5 seconds.
- Long target: one scene about every 5-7 seconds. Do not keep the same scene for more than 10 seconds.
- End each scene with a line that makes the viewer curious about the next scene.
- Each scene background must be visually different from the previous scene. Do not use the same composition repeatedly.
- For every `背景:` line, specify at least 3 of: composition, camera distance, setting, color mood, visual style.
- Shorts backgrounds should rotate between: list/wanted-poster view, close-up, diagram, comparison, warning visual, package/table/store view, solution scene.
- For Shorts, keep the lower half of the background clear. Food, diagrams, text, and key visuals must be placed in the upper half or upper center. The lower half is reserved for character sprites and subtitles.
- Add this phrase to every Shorts background prompt: `前シーンとは構図・距離感・色味を変える。画面下半分はキャラ立ち絵用に余白を広く空ける。`

Output example:

背景: Japanese image prompt. Manga illustration style. No people. Put the short catch copy "Cheap before" at the top center in white bold text with thick black outline.
テロップ: Cheap before

Shorts導線方針：ループ優先ルール
━━━━━━━━━━━━━━━━━━

Shortsでは、他動画への直接誘導よりも、
その動画を最後まで見てもらうこと、もう一周見てもらうことを最優先する。

理由:
・Shortsでは他動画クリックより、平均視聴率・完走率・ループ視聴の価値が高い
・「次回は〇〇」などの告知は、視聴者に終わった感を与えやすい
・最後はフィード再配布につながる視聴維持を優先する

原則:
・Shorts本編では「次回は〇〇をやるのだ」のような明確な次回予告は禁止
・「他の動画も見てね」「次の動画も見てね」などの直接誘導は禁止
・最後は、冒頭のキーワードやサムネ文字に戻るループ構成を優先する
・他動画誘導は、Shorts本編ではなく固定コメント・説明欄・Longで行う

良い締め方:
・冒頭の強い言葉に戻る
・オチの後に、もう一度見たくなる違和感を残す
・「他にも〇〇が怪しいのだ」のようにチャンネル期待値を残す
・ただし、具体的な次回予告にはしない

悪い例:
ずんだもん(ノーマル): 次回はエンガワを解説するのだ
四国めたん(ノーマル): チャンネル登録して待っててね

良い例:
四国めたん(ツンツン): 団地の名前、信用できませんわ
ずんだもん(ノーマル): 他の団地ネタも怪しいのだ

良い例:
四国めたん(ツンツン): 飲み物の昔、クセ強すぎですわ
ずんだもん(ノーマル): 他の飲み物も薬っぽいのだ

━━━━━━━━━━━━━━━━━━

「ネタ募集CTA: 許可」の場合のみ、台本末尾でネタ募集CTAを使ってよい。

発動条件:

1. ループ締め
2. 自然なコメント誘導
3. ネタ募集CTA

つまり、ネタ募集CTAを入れても、

【穴シリーズ優先横展開】
バウムクーヘン・マカロニ・ベーグルで成立確認済み。穴・空洞・形状の理由系は高優先横展開候補。
「○○に穴がある本当の理由」の連発は避け、冒頭フックのアプローチを変える。
次候補: ちくわ、ドーナツ、れんこん、アイスの棒、ストロー菓子など。
台本では「穴がないと〇〇できない」「穴があるから〇〇が生まれた」など、必然性・驚きを冒頭で断言する。

【腐らない・長持ち系の台本方針】
外食チェーン・コンビニ・日常購入品に寄せる。心霊スポット単体は科学説明になりやすいため避ける。
マックポテト型: 「自分が食べてるアレがなぜ腐らないのか」という自分事視点で冒頭を作る。

【昔は違った系の台本方針】
現在イメージとの落差が大きいものだけ採用する。
サーモン型（優先）: 今や当たり前だが昔は嫌われていた → ギャップで驚かせる構成が強い。
トロ型（優先度下げ）: 既知情報が多いものは優先度を下げる。

【弱動画の反省を台本に反映】
・心霊スポット型失敗パターン: 事実の羅列・科学説明に偏った台本 → 「人間との感情的なエピソード」に変換する
・人参型: 入口フックが弱い → 冒頭1秒で「今の人参と昔の人参は別物」のような認識破壊で開始する
・定番型: 真相だけで終わらず、「現代でも残っている痕跡」「今行くと〇〇に感じる」まで掘る
・メロンパン型: 名前ネタを単体ネタにしない。切り口を「形の理由」「工場の秘密」にシフトする

【配布不足・反応強い動画の台本方針】
like_rate が高いがviewsが少ない動画は、ネタ自体は強い可能性がある。
ジンジャーエール型: 「薬っぽい飲み物」シリーズの冒頭フックとして、医薬品と飲み物の境界の驚きを軸にする。
冒頭は「ジンジャーエールは昔、病院で出される飲み物だった」のように自分事化できる断言から始める。

## めたんの役割
めたんは「解説役」でも「相槌役」でも「共同解説者」でもない。
めたんは「視聴者代表の強毒舌ツッコミ役・辛口編集者」として固定する。
ずんだもん: 事実を出す / 理由を説明する / 情報を届ける
めたん: 視聴者の疑問を先に代弁する / ずんだもんの説明の弱さを毒舌で刺す / テンポを作る
めたんが情報を説明してはいけない。情報の主導権はずんだもんに置く。

## めたんのセリフ必須条件
めたんの各セリフは必ず以下のどれかを含める:
1. 視聴者の疑問（例: 穴だけで見る理由ありますの？ / なんで高級品が昔はただの道ですの？）
2. 毒舌ツッコミ（例: その入り、弱すぎてスワイプ案件ですわ / 名前でだます気満々ですわ）
3. 反論・疑い（例: まだ普通の工夫にしか聞こえませんわ / それで視聴者の指、止まりますの？）
4. 皮肉・違和感（例: 飾りだと思わせて製造都合ですの / 人間、急にありがたがりすぎですわ）
5. 辛口の視聴者目線（例: それ最初に言いなさい / ようやく見る理由が出ましたわ）

## めたんの禁止セリフ（完全一致・同等の意味も禁止）
「えっ？」「なるほどですわ」「そうなのですわね」「すごいですわ」「知らなかったですわ」「不思議ですわね」
「便利ですわね」「大事ですわね」「強いですわね」「面白いですわね」「そういうことですわね」
「つまり〇〇ですわね」「〇〇ということですわね」「〇〇が理由ですわね」「〇〇になりますわ」

毒舌のNG対象（絶対禁止）: 視聴者を馬鹿にする / 都市伝説そのものを汚く罵る / 国/地域/文化を下げる / 特定企業/人物を攻撃する / 人格否定 / 差別的発言

## Shortsでの毒舌頻度と配置
- 強め毒舌を5〜7回入れる / 冒頭2行目は原則強毒舌 / 中盤真相判明で1回強く刺す / ラストは毒舌オチ
- 毒舌でも必ず情報を進める（毒舌で会話を止めない）

## 掛け合い良い例
ずんだもん(ノーマル): ちくわは穴なしだと作れないのだ
四国めたん(ツンツン): 穴だけで見る理由ありますの？
ずんだもん(ノーマル): すり身を棒に巻いて焼くのだ
四国めたん(ツンツン): 飾りだと思わせて製造都合ですの
ずんだもん(焦り): 棒を抜くと穴が残るのだ
四国めたん(ツンツン): 最初からそれを出しなさいですわ
ずんだもん(ノーマル): しかもだしも通るのだ
四国めたん(ツンツン): 穴、働きすぎて主役面ですわ

## 掛け合い悪い例（生成禁止）
ずんだもん(ノーマル): ちくわは穴が大事なのだ
四国めたん(ノーマル): なるほどですわ  ← 禁止
ずんだもん(ノーマル): だしが通るのだ
四国めたん(ノーマル): 便利ですわね  ← 禁止（共同解説者になっている）

## 生成後チェック（不合格条件）
以下に1つでも当てはまる場合は作り直す:
- めたんに相槌だけのセリフが1つでもある
- めたんが共同解説者のように情報を説明している
- めたんの毒舌・疑問・反論・皮肉・違和感が5回未満
- 冒頭2行目がめたんの強いツッコミになっていない
- ラストがめたんの毒舌オチになっていない
- 視聴者・文化・食品そのものへの攻撃がある

## 絶対条件（違反したら出力前に自己修正）
- セリフ数: 24〜27行を標準。22〜23行は原則禁止。21行以下は完全不合格
- セリフ本文合計: 280〜330文字。260〜279文字は不合格扱いで自己補正
- 平均文字数: 11.5〜13.5文字を狙う
- 10文字以下の短文: 最大4行まで
- 7文字以下の短文: 原則禁止
- 15文字超え: できるだけ避ける
- 複数本生成時もすべての台本が24〜27行・280〜330文字を満たすこと。1本でも違反したら不合格

「7シーン×3セリフ」は21行になり不合格。禁止構成。

## 推奨構成A（最優先）
8シーン × 3セリフ = 24行

Scene 1 Opening hook: ずんだもん断言 / めたん強毒舌 / ずんだもん理由入口
Scene 2 First doubt: めたん視聴者目線疑問 / ずんだもん最初の理由
Scene 3 Core reason: ずんだもん核心理由 / めたん弱さや違和感を刺す
Scene 4 Second surprise: 15〜25秒地点の第2驚き / 原因・逆転・具体例
Scene 5 Concrete example: 身近な例・食感・売り場・食卓に寄せる
Scene 6 Extra twist: もう一段の意外性・昔と今の差・名前の罠
Scene 7 Character beat: ずんだもんのお茶目な反応 / めたんの毒舌でキャラを立てる（情報は止めない）
Scene 8 Loop ending: コメント誘導1行 / めたんの毒舌オチ / 冒頭キーワードへ戻す

## 推奨構成B（7シーンの場合）
7シーンにする場合は必ず3シーン以上を4セリフにする。合計24〜25行。
7シーンすべて3セリフ（21行）は禁止。

## 出力前セルフチェック（必須）
1. セリフ行数が24〜27行か
2. セリフ本文合計が280〜330文字か
3. 260〜279文字で止まっていないか
4. 10文字以下の短文が4行以内か
5. めたんの毒舌・疑問・反論・皮肉・違和感が5回以上あるか
6. めたんのセリフが相槌・共同解説になっていないか
7. 冒頭2行目がめたんの強いツッコミになっているか
8. ラストに毒舌オチがあるか
9. 複数本生成時は全台本が上記を満たしているか

## 台本量不足の自動補正（24行未満になりそうな場合）
追加OK: めたんの視聴者目線疑問 / 毒舌ツッコミ / ずんだもんの追加事実 / 身近な具体例
追加NG: 相槌 / 雑なリアクション / 意味のないギャグ / 登録・高評価・他動画誘導 / 同じ情報の言い換えだけ

## 文字数不足の自動補正
「雑ですわ」→「昔の判断が雑すぎますわ」
「弱いですわ」→「その入りは弱すぎますわ」
「うまいのだ」→「そこが定番化した理由なのだ」

## 冒頭3行必須ルール
1行目: 場所やテーマ + 意外な結論
2行目: めたんの強毒舌・疑問・反論
3行目: ずんだもんが理由の入口
