vidIQ運用メモ:
・当面はShorts集中。Longは主力にせず、Shortsで実績が出たネタの深掘り候補に限定する。
・Longを増やすより、Shortsの維持率とコメント率を優先する。
・タイトル案の最優先型は「思い込み破壊型」（名前が嘘・発祥の勘違い・昔の扱いが今と真逆・薬/毒/危険視・容器包装形の理由）。
・特に「外国怪談に見えるが日本発」「名前から想像する正体と違う」「昔は捨てられた/嫌われた/怖がられた」を優先する。
・「へぇ」で終わる説明型ではなく、「自分も勘違いしていた」と思わせるタイトルを優先する。
・めたんファーストは継続テスト中。全件固定ではなく、思い込み破壊型・名前の罠・発祥の勘違い・毒舌ツッコミが映えるテーマで優先する。
・data_wait動画は横展開判断の根拠にしない。views/likesのみ暫定参考にする。
・タイトルは冒頭1〜3行で核心を回収できるものにする。「今日は〜」「今回は〜」前提のタイトルは禁止。
・Shorts案は15〜30秒地点に2つ目の驚き、逆転、具体例を入れられる構造を優先する。
・コメントしやすい問いに落とせる案を加点する。例: どっち派 / 他にも知ってる / これ知ってた。
・通常は1ネタ深掘りを主力にし、3選・クイズは実験枠に留める。
・タイトル本文に「雑学 ショート」「ゆっくり解説」を不自然に入れない。タグ・説明欄で補完する。
・タグには「雑学 ショート」「ゆっくり解説」「ゾッとする話」を必ず含める。
・説明文冒頭1〜2行には、動画の答えが分かる自然文の要約を入れる。
・固定コメントは、動画内容の要約1文 + コメントしやすい質問1文にする。
・タグは共通タグ（都市伝説 / ゾッとする話 / 怖い話 / ゆっくり解説 / ゆっくり解説 怖い話 / ずんだもん / ずんだもん解説 / 四国めたん / VOICEVOX / 雑学ショート）と題材別タグを併用する。

【穴シリーズ優先横展開】
バウムクーヘン・マカロニ・ベーグルで成立確認済み。穴・空洞・形状の理由系は高優先横展開候補。
ただし「○○に穴がある本当の理由」の連発は避け、タイトル表現を変える。
次候補: ちくわ、ドーナツ、れんこん、アイスの棒、ストロー菓子など。

【配布不足・反応強い動画の扱い】
views < 1000 でも like_rate >= 2.5% または likes >= 20 の動画は失敗扱いにしない。
action に「反応強い」が付いている動画は横展開起点として優先検討する。
例: ジンジャーエール → 薬っぽい飲み物シリーズの起点候補。

【腐らない・長持ち系の採用基準】
心霊スポットのような一般場所単体は既知感・科学説明化で弱くなりやすい。
マックポテトのように、自分も食べている身近な商品・ブランド・店に紐づく場合は優先度を上げる。
腐らない系は「外食チェーン・コンビニ・日常購入品」に寄せて採用すること。

【昔は違った系の採用基準】
現在のイメージとの落差が大きいものだけ採用する。
・サーモン型（優先）: 現在の人気・高級感が強く、昔の低評価とのギャップが大きいもの
・トロ型（優先度下げ）: 既知情報になりやすいものは優先度を下げる
次候補: ロブスター・カニカマ・チキン・タコ・サーモン系横展開。

【弱動画の分類（即ブラックリストにしない）】
・心霊スポット: 有名ネタ・心霊解説型 → リベンジは怪談エピソード型で切り口を変える
・人参: 反応は強いので入口改善候補。ネタ自体は捨てない
・納豆フィルム: 自分事化できなければブラックリスト候補
・プリン: 具体エピソード化すれば改善余地あり
・メロンパン: 有名すぎる名前ネタ消耗型。通常切り口は避ける
