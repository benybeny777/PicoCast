Shortsループ構成ルール
━━━━━━━━━━━━━━━━━━

Shortsは、最後の1〜2セリフが冒頭の衝撃事実に自然につながるように作る。

目的:
・視聴者が無意識にもう一周見たくなる
・最後で話を閉じすぎない
・冒頭のセリフが2周目でさらに意味を持つ
・平均視聴率100%以上を狙う

基本構成:
1. 冒頭で衝撃事実を断言
2. 中盤で理由を小出しにする
3. 終盤で意外なオチを出す
4. 最後のセリフで冒頭の言葉に戻る

禁止:
・「以上です」
・「終わりです」
・「まとめると」
・「チャンネル登録お願いします」
・完全に話を閉じる締め
・長いCTA
・余韻のない説明終わり

推奨:
・最後に冒頭と同じキーワードを再登場させる
・最後に「だから〇〇なのだ」と戻す
・最後にめたんのツッコミで冒頭へつなぐ
・最後のセリフを短く強くする
・コメント誘導は1セリフだけにする

ループ例1:
冒頭:
ずんだもん(ノーマル): トマトは毒扱いだったのだ
ラスト:
四国めたん(ツンツン): 今ならサラダの主役ですわ
ずんだもん(ノーマル): でも昔は毒扱いなのだ

ループ例2:
冒頭:
ずんだもん(ノーマル): メロンパンにメロンはないのだ
ラスト:
四国めたん(ツンツン): 名前だけ強すぎですわ
ずんだもん(ノーマル): だからメロンはないのだ

ループ例3:
冒頭:
ずんだもん(ノーマル): ナポリタンは日本生まれなのだ
ラスト:
四国めたん(ツンツン): 名前だけ海外ぶるなですわ
ずんだもん(ノーマル): でも日本生まれなのだ

CTAを入れる場合:
・コメント誘導はラスト2〜3セリフ以内
・ループを壊さない
・固定コメントと同じ問いにする

CTAありループ例:
ずんだもん(ノーマル): 日本食派か洋食派か
四国めたん(ノーマル): コメントで教えてですわ

自己チェック:
・最後のセリフから冒頭に戻っても違和感がないか
・最後で話を閉じすぎていないか
・冒頭キーワードがラストにも出ているか
・CTAが長すぎないか
・ラストが説明ではなく感情かツッコミになっているか

・詰め込みすぎず、視聴者が一瞬で理解できる流れにする

CTAルール（事務的禁止）
━━━━━━━━━━━━━━━━━━

CTAは「お願い」ではなく、オチの流れで自然に入れる。

禁止CTA:
・チャンネル登録お願いします
・高評価お願いします
・他の動画も見てね
・コメントしてください
・登録も忘れずに

CTAは必ず以下のどれかにする。

1. オチ連動型: 直前のオチを受けてそのままコメント誘導
例:
四国めたん(ツンツン): 穴で稼ぐなですわ
ずんだもん(ノーマル): 穴あり派かコメントで教えて

2. 視聴者参加型: 二択の問いでコメント誘導
例:
ずんだもん(ノーマル): 穴あり派か穴なし派か
四国めたん(ノーマル): コメントで教えてですわ

3. 感情ツッコミ型: めたんのツッコミを最後の印象にする
例:
ずんだもん(ノーマル): 感想をコメントで教えて
四国めたん(ツンツン): 穴で稼ぐなですわ

4. 続き見たくなる型: 次の食べ物雑学が気になる言い方
例:
ずんだもん(ノーマル): 他の食べ物も昔はヤバいのだ
四国めたん(あまあま): 見逃せませんわ

Scene-Based Script Generation
------------------------------

- Generate the main script scene by scene.
- Use a comment heading before each scene: `# Scene 1: Opening hook`, `# Scene 2: Reason`, etc.
- The `# Scene ...` heading is for management and is ignored by the app.
- Each scene must start with exactly one `背景:` line.
- Add `テロップ:` only when needed. It must be a short summary, not a copy of dialogue.
- Put several dialogue lines inside one scene.
- Do not split every single dialogue line into a separate scene.
- Move to the next scene when the topic, place, era, emotion, or visual point changes.
- Shorts target: 6-9 scenes, with a visual change about every 3-5 seconds.
- Long target: one scene about every 5-7 seconds. Do not keep the same scene for more than 10 seconds.
- End each scene with a line that makes the viewer curious about the next scene.

Output example:
# Scene 1: Opening hook
背景: Japanese image prompt. Manga illustration style. No people. Put the short catch copy "Cheap before" at the top center in white bold text with thick black outline.
テロップ: Cheap before
ずんだもん(ノーマル): セリフ
四国めたん(ツンツン): セリフ

# Scene 2: Reason
背景: Japanese image prompt for an old food shop. No people. Put the short catch copy "Old style" at the top center in white bold text with thick black outline.
ずんだもん(ノーマル): セリフ
四国めたん(ノーマル): セリフ
