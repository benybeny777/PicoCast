既知ネタ深掘りルール
━━━━━━━━━━━━━━━━━━

台本化する前に、テーマが「誰でも知っている話」になっていないか確認する。

以下に当てはまる内容を、台本の中心にしてはいけない。

・見た目や食べ方で分かる話
・タイトルだけで結論が分かる話
・SNSやテレビで定番化している雑学
・小学生でも知っていそうな話
・説明しても「知ってた」で終わる話
・単なる商品特徴の説明
・公式サイトの商品説明をなぞるだけの話

既知度が高い場合は、台本の中心を以下にズラす。

1. なぜそう作られたのか
2. どう改良されたのか
3. 昔はどう違ったのか
4. どんな失敗を解決したのか
5. 味や香りがどう感じ方を変えるのか
6. 包装、容器、店内導線などの工夫
7. 視聴者が誤解しているポイント
8. 名前と実物のズレ

台本内では、
「誰でも知っている事実」は冒頭か前半で一瞬だけ触れる。
その後すぐに、知られていない理由・背景・仕組みに移る。

悪い例:
カップ焼きそばは焼いてない。
お湯で戻す。
ソースを混ぜる。
だから焼いてない。

良い例:
カップ焼きそばの本体は湯切りだった。
湯を捨てるだけで、焼きそばっぽくなるように作られている。
ソースの香りで焼いた感じを補っている。
だから焼いてないのに焼きそばに感じる。

悪い例:
ファミチキは袋に入っている。
袋のまま食べやすい。
だからうまく感じる。

良い例:
ファミチキの袋は香りを逃がしにくい。
開けた瞬間に香りが一気に来る。
熱と手軽さで「今食べたい」が強くなる。
だから袋まで味の一部に感じる。

自己チェック:
・台本の中心が「知ってる話」になっていないか
・1つ以上、知られていない理由や仕組みが入っているか
・商品説明をなぞるだけになっていないか
・視聴者が「それ知ってる」で離脱しない構成か
・冒頭の後、すぐ深掘りに入っているか

冒頭3行は「前置き」ではなく「答えの入口」にする。

1行目: 食べ物の意外な事実を断言する
2行目: 視聴者の疑問を代弁する（めたんが言う）

禁止:

・「今回は〇〇の理由を紹介するのだ」
・「〇〇について話すのだ」

推奨:
・1行目で「何の話か」と「なぜ驚くのか」が同時に分かる形にする
・2行目はめたんが視聴者の疑問を自然に代弁する
・3行目が理由・仕組みの答えの入口になる
・上品で分かりやすい引きを優先する
・知的好奇心で引く型を最優先にする

Shortsの冒頭は、重大エラーを避けつつ自然な日本語で強くする。
80点以上を理想にするが、自然で意味が通るタイトル・冒頭を優先する。

冒頭1行目は必ず以下をすべて満たす。

・食べ物名を入れる
・意外性が伝わる言葉を入れる
・1行だけで意味が完結する
・2行目を読まないと意味が分からない形にしない
・タイトル、サムネ文字、冒頭テロップの意味の方向を揃える
・サムネに書いた衝撃ワードを5秒以内に回収する
・サムネと冒頭の内容がズレる構成は禁止

冒頭1行目の型:
食べ物名 + 意外性 + 結論

良例:
ずんだもん(ノーマル): カシューナッツがヤバすぎる
ずんだもん(ノーマル): うなぎの夏はヤバい
ずんだもん(ノーマル): トマトは毒扱いだったのだ

悪例:
ずんだもん(ノーマル): カシューナッツは
ずんだもん(ノーマル): 実の外なのだ

悪例:
ずんだもん(ノーマル): うなぎの夏は
ずんだもん(ノーマル): 売る作戦なのだ

強い意外性ワード（推奨）:
・ヤバい
・ヤバすぎる
・怖すぎる
・毒扱い
・禁止
・貧乏飯
・高級品
・真逆
・捨てられた
・薬だった
・別物だった
・作られた
・実は違う
・食べられなかった

自然ワード（これだけでも意味が強ければ可）:
・実の外
・薬屋
・作戦
・代用品
・王族の味
・庶民の味
・名前だけ
・外側
・手間すぎ
・日本生まれ

自然ワードだけで弱く見える場合は、2行目でめたんに強く反応させる。

サムネ・テロップ・冒頭接続:

・完全一致は不要
・意味の方向が揃っていればよい
・意味がズレる組み合わせは禁止
・テロップだけ強く、セリフが弱すぎる形は避ける
・サムネの衝撃ワードは冒頭5秒以内に必ず言葉か同義表現で回収する
・サムネだけ強くして、冒頭で別の説明から入る構成は禁止

例:

サムネ文字: ヤバすぎ
テロップ: ヤバすぎ
冒頭:
ずんだもん(ノーマル): カシューナッツがヤバすぎる

例:
動画タイトル: カシューナッツは実の外にあった
サムネ文字: 実の外
テロップ: 変な実り方
冒頭:
ずんだもん(ノーマル): カシューナッツは実の外

Shortsループ構成ルール
━━━━━━━━━━━━━━━━━━

Shortsは、最後の1〜2セリフが冒頭の衝撃事実に自然につながるように作る。

目的:
・視聴者が無意識にもう一周見たくなる
・最後で話を閉じすぎない
・冒頭のセリフが2周目でさらに意味を持つ
・平均視聴率100%以上を狙う

基本構成:
1. 冒頭で衝撃事実を断言
2. 中盤で理由を小出しにする
3. 終盤で意外なオチを出す
4. 最後のセリフで冒頭の言葉に戻る

禁止:
・「以上です」
・「終わりです」
・「まとめると」
・「チャンネル登録お願いします」
・完全に話を閉じる締め
・長いCTA
・余韻のない説明終わり

推奨:
・最後に冒頭と同じキーワードを再登場させる
・最後に「だから〇〇なのだ」と戻す
・最後にめたんのツッコミで冒頭へつなぐ
・最後のセリフを短く強くする
・コメント誘導は1セリフだけにする

ループ例1:
冒頭:
ずんだもん(ノーマル): トマトは毒扱いだったのだ
ラスト:
四国めたん(ツンツン): 今ならサラダの主役ですわ
ずんだもん(ノーマル): でも昔は毒扱いなのだ

ループ例2:
冒頭:
ずんだもん(ノーマル): メロンパンにメロンはないのだ
ラスト:
四国めたん(ツンツン): 名前だけ強すぎですわ
ずんだもん(ノーマル): だからメロンはないのだ

ループ例3:
冒頭:
ずんだもん(ノーマル): ナポリタンは日本生まれなのだ
ラスト:
四国めたん(ツンツン): 名前だけ海外ぶるなですわ
ずんだもん(ノーマル): でも日本生まれなのだ

CTAを入れる場合:
・コメント誘導はラスト2〜3セリフ以内
・ループを壊さない
・固定コメントと同じ問いにする

CTAありループ例:

四国めたん(ノーマル): コメントで教えてですわ
ずんだもん(ノーマル): でも日本生まれなのだ

自己チェック:
・最後のセリフから冒頭に戻っても違和感がないか
・最後で話を閉じすぎていないか
・冒頭キーワードがラストにも出ているか
・CTAが長すぎないか
・ラストが説明ではなく感情かツッコミになっているか

Shortsの情報量:
・驚き事実を1つ大きく見せる
・補足の小ネタは1〜2個まで
・詰め込みすぎず、視聴者が一瞬で理解できる流れにする

CTAルール（事務的禁止）
━━━━━━━━━━━━━━━━━━

・他の動画も見てね
・コメントしてください
・登録も忘れずに

CTAは必ず以下のどれかにする。

1. オチ連動型: 直前のオチを受けてそのままコメント誘導
例:

ずんだもん(ノーマル): 穴あり派かコメントで教えて

2. 視聴者参加型: 二択の問いでコメント誘導
例:

例:
ずんだもん(ノーマル): 感想をコメントで教えて
四国めたん(ツンツン): 穴で稼ぐなですわ

4. 続き見たくなる型: 次の食べ物雑学が気になる言い方
例:
ずんだもん(ノーマル): 他の食べ物も昔はヤバいのだ
四国めたん(あまあま): 見逃せませんわ

Scene-Based Script Generation
------------------------------

- Generate the main script scene by scene.
- Use a comment heading before each scene: `# Scene 1: Opening hook`, `# Scene 2: Reason`, etc.
- The `# Scene ...` heading is for management and is ignored by the app.
- Each scene must start with exactly one `背景:` line.
- Add `テロップ:` only when needed. It must be a short summary, not a copy of dialogue.
- Put several dialogue lines inside one scene.
- Do not split every single dialogue line into a separate scene.
- Move to the next scene when the topic, place, era, emotion, or visual point changes.
- Shorts target: 6-9 scenes, with a visual change about every 3-5 seconds.
- Long target: one scene about every 5-7 seconds. Do not keep the same scene for more than 10 seconds.
- End each scene with a line that makes the viewer curious about the next scene.

Output example:
# Scene 1: Opening hook
背景: Japanese image prompt. Manga illustration style. No people. Put the short catch copy "Cheap before" at the top center in white bold text with thick black outline.
テロップ: Cheap before
ずんだもん(ノーマル): セリフ
四国めたん(ツンツン): セリフ

# Scene 2: Reason
背景: Japanese image prompt for an old food shop. No people. Put the short catch copy "Old style" at the top center in white bold text with thick black outline.
ずんだもん(ノーマル): セリフ
四国めたん(ノーマル): セリフ
