# 動画履歴・素材の取り込み

WP-R1-4は `Store::import_legacy_channel` を使う。設定取り込み済みのチャンネルを明示し、オンラインバックアップ済みmetadata DB・出力コピーの実体・旧DB内の元出力ルート・共通CAS保存先・元タイムゾーンを指定する。運用元がlegacy以外のチャンネルには書かない。

動画・台本原文・YouTube状態・固定コメント・再生リスト・期間累計Analytics・未知表の全行をrevisionと監査snapshotへ保持する。日別でない旧分析値を日別値として捏造しない。台本のScene/Lineへの解析はWP-R2-2、専用列のない投稿状態等の消費は各後続WPで実装する。

元DBのSHA-256、全素材のSHA-256、取り込み前後のファイル集合を照合する。同じ内容の素材は共通CASへ集約し、チャンネル共通素材はchannel所有とする。DB/WAL/鍵/token/.envは素材にせず、除外対象の名前だけを報告する。リンクや元出力外へのパスは拒否する。

対応プロセスを照合していないrunningはabandonedとして保存する。起動時刻・チャンネル・実行内容を呼出側で確認したPIDだけlegacy_runningへ写像し、待機中はlegacy_queuedとして保持する。自動で実行し直さず、原記録は残す。

同入力の再実行は同じ結果となり、宛先の編集との不一致は上書きせず全トランザクションを取り消す。コピー済みの共有CASを誤削除しないため、DB失敗時も未参照実体は残る場合がある。

合成fixture8件で、原記録の保持・冪等性・素材照合・ファイル追加検出・越境拒否・保護ファイル除外・全rollbackを確認した。本番コピーでの全件照合とCLI受入は未実施。
