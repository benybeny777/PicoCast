SD WebUI セットアップ手順

SD WebUI（Forge / AUTOMATIC1111）が起動していません。以下の手順で起動してください。

  1. SD WebUI Forge をインストールしてください。
    https://github.com/lllyasviel/stable-diffusion-webui-forge
  2. SD WebUI を --api オプション付きで起動します。
    webui-user.bat（Windows）を編集して COMMANDLINE_ARGS=--api を追記するか、
    コマンドラインから直接 python launch.py --api で起動してください。
  3. 起動後は http://localhost:7860（デフォルト）で動作確認し、ページをリロードしてください。
  4. ポートが異なる場合は .env の SD_WEBUI_BASE_URL を変更してください。
    例: SD_WEBUI_BASE_URL=http://localhost:7860
  5. SD WebUI が自動起動するよう設定したい場合は .env の SD_WEBUI_START_COMMAND を設定してください。
    例: SD_WEBUI_START_COMMAND=C:\sd.webui\run.bat --api --nowebui

設定は 設定ページ から変更できます。
